# NEXORA AI

**Simulate. Predict. Optimize.**

NEXORA AI is a multi-domain scenario simulation and decision-support prototype. It lets users adjust planning inputs, inspect calculated capacity metrics, compare saved scenarios, and export a PDF summary.

## Simulation modules
- Traffic & Transportation
- Business & Inventory
- Logistics & Delivery
- Energy Management
- Emergency Planning

## Features
- Interactive Streamlit dashboards and Plotly charts
- Transparent, rule-based recommendations
- Local scenario save/load and side-by-side input comparison
- PDF simulation reports
- Optional Supabase authentication and per-user cloud scenario storage

> Outputs are illustrative planning estimates, not live operational predictions. Validate assumptions before real-world use. Recommendations are rule-based; this prototype does not claim to use a trained AI model.

## Run locally
Use Python 3.13, then install dependencies and start the app:

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Optional Supabase cloud sync
Add the Supabase project URL and public anon/publishable key to `.streamlit/secrets.toml`:

```toml
[supabase]
url = "https://YOUR-PROJECT.supabase.co"
anon_key = "YOUR_SUPABASE_ANON_KEY"
```

Never commit credentials or use the service-role key in this client app.

Create the table in Supabase SQL Editor (if it already exists, inspect it and apply only missing changes):

```sql
create table if not exists public.scenarios (
  id bigint generated by default as identity primary key,
  user_id uuid not null references auth.users(id) on delete cascade,
  name text not null,
  domain text not null,
  inputs jsonb not null default '{}'::jsonb,
  created_at timestamptz not null default now()
);

alter table public.scenarios enable row level security;
grant select, insert, update, delete on public.scenarios to authenticated;
grant usage, select on sequence public.scenarios_id_seq to authenticated;

create policy "Users can read their own scenarios"
on public.scenarios for select to authenticated using (auth.uid() = user_id);
create policy "Users can insert their own scenarios"
on public.scenarios for insert to authenticated with check (auth.uid() = user_id);
create policy "Users can update their own scenarios"
on public.scenarios for update to authenticated
using (auth.uid() = user_id) with check (auth.uid() = user_id);
create policy "Users can delete their own scenarios"
on public.scenarios for delete to authenticated using (auth.uid() = user_id);
```

Cloud sync requires email/password authentication. Row-level security restricts each user to their own scenarios. If SQL execution is unavailable, use the Supabase dashboard's table privileges and RLS policy editor; do not disable RLS.
